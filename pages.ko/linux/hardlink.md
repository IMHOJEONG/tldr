# hardlink

> 중복 파일을 하드 링크로 대체하여 통합.
> `util-linux`의 일부로, 여러 디렉터리에 동일한 파일이 있을 때 디스크 공간을 절약하는 데 유용.
> 더 많은 정보: <https://manned.org/hardlink>.

- 파일을 변경하지 않고 dry run을 수행:

`hardlink {{[-n|--dry-run]}} {{경로/대상/디렉터리}}`

- 디렉터리의 중복 파일을 하드 링크로 통합:

`hardlink {{경로/대상/디렉터리}}`

- 여러 디렉터리의 중복 파일을 하드 링크로 통합:

`hardlink {{경로/대상/디렉터리1 경로/대상/디렉터리2 ...}}`

- 자세한 출력과 함께 하드 링크를 생성:

`hardlink {{[-v|--verbose]}} {{경로/대상/디렉터리}}`

- 지정한 최소 크기 이상의 파일만 대상으로 하드 링크 생성:

`hardlink {{[-s|--minimum-size]}} {{size}} {{경로/대상/디렉터리}}`
